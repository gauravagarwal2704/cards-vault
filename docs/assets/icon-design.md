# Burgundy brand icon

Asset: `app-icon-rose.png` (256 × 256 PNG).

Created with the built-in imagegen tool using the existing CardVault icon as the reference. This artwork was the reference for the default burgundy native app icon. The app icon has since been redrawn at high resolution with a gold inner vault dial; its master is `play-store-assets/icon-options/cardvault-burgundy-master.png`. The matching 512 × 512 Play Store export is `play-store-assets/icon-options/cardvault-play-burgundy.png`; native launcher sizes and `assets/branding/app_icon_burgundy.webp` are downscaled from that high-resolution master.

Final prompt:

> Create a FLAT 2D version of this CardVault icon. Preserve its recognizable silhouette: left credit card with small gold chip merging into a circular vault dial on the right. Remove ALL 3D extrusion, bevels, gradients, glossy edges, glares, shadows and lighting effects. Use clean flat solid fills with main symbol exact dusty burgundy rose #91435C, optional tiny flat lighter rose accent #C593A4, small flat muted gold chip #D4AE65. Background flat warm cream #FBF6F2. Simple crisp vector-like geometry, uniform shapes, no outline bevel, no text, no reflections. Center symbol, square app icon, strong small-size legibility. Save locally for website integration.


## Sharp burgundy and gold app icon

The master is retained at its generated resolution. Every native size and the opaque 512 × 512 Play Store export is downscaled directly from the master, avoiding enlargement of the original 256 × 256 website icon.
